# ReproLLM 0.5.0a1 — release record (2026-09-28)

Pre-release (PEP 440): `pip install reprollm` does not select it; use
`pip install --pre reprollm==0.5.0a1`. The Beta final `0.5.0` follows in M8.

Scope: the complete M7 feature face — `export`, project rules end-to-end,
and the experimental `discover` (delivered inside its three-day time box; the
cut clause was not needed). Plus one dogfooding fix: `lock --offline` no
longer constructs an HTTP client (SOCKS-proxy environments crashed offline
locking).

Validation at release time: full quality matrix (1285+ tests on 3.10–3.12,
ruff, mypy --strict, schema freshness, both coverage gates), five-repository
Gate A, and the five-repository full flow init → audit L1 → lock --offline →
audit L2 → export in disposable worktrees. Real-resource gates: DeepSeek
judge and DistilGPT2 DP are the formal standards (val.md §8.5); the lm-eval
clean re-pair and HarmBench local pair wait for GPU availability and are not
claimed. Real discover execution awaits a provisioned endpoint/budget; only
dry-runs are claimed.
