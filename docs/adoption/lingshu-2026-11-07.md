## Public citation scope

The public trial report and contributor-authored upstream #16/#17 explicitly
offer this workflow as a public tutorial. This review links those public
documents and code only. It does not republish private logs, author contact
details, medical images, checkpoint bytes, credentials or unpublished results.
Public tutorial contribution is not blanket permission to disclose private assets.

0.7.0 and its `.pth` extension are unreleased. Application report success,
upstream acceptance and package publication remain three separate claims.
