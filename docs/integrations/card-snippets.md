# Model and dataset card snippets

Copy-paste snippets for Hugging Face model and dataset cards that ship
ReproLLM reproducibility artifacts.

## Model card snippet

```markdown
## Reproducibility

This model repository ships a [`reprollm.lock`](./reprollm.lock) recording
the exact model revision, tokenizer revision, and chat-template hash used in
our experiments. To verify:

```bash
pip install reprollm
reprollm audit .
```

The audit reports model identity, dependency pins, and any drift since the
lock was generated. See [ReproLLM](https://github.com/EnumaElish123/ReproLLM).
```

## Dataset card snippet

## Reproducibility

Experiments using this dataset declare it in `reprollm.yaml` with the exact
revision and split. The committed [`reprollm.lock`](./reprollm.lock) records
the resolved dataset revision hash.

```bash

```
```

## Paper artifact README snippet

```markdown
## Reproducibility

This artifact includes:
- `reprollm.yaml` — the experiment manifest (what was intended)
- `reprollm.lock` — resolved model/dataset revisions (what was used)
- `.reprollm/runs/` — recorded executions (what actually ran)
- `REPRODUCIBILITY.md` — generated by `reprollm export`

To reproduce:
```bash
pip install reprollm
reprollm audit .
reprollm diff <reported-run-id> <your-run-id>
```
```
