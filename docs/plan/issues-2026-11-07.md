### 精确规范替换

只替换 `docs/plan/01_specification.md` §4.3 表格的 `local` 行。

原文：

```text
| `local` | `id` must exist. Directory: hash `config.json`, `tokenizer_config.json`, `tokenizer.json` if present; weights files (`*.safetensors`, `*.bin`, `*.gguf`, `*.pt`) hashed only with `--hash-large-files` or if total ≤ 100 MiB; otherwise `weights.hashed: false`. |
```

方案 A 新文：

```text
| `local` | `id` must exist. Directory: hash `config.json`, `tokenizer_config.json`, `tokenizer.json` if present; recursively select regular weight files by case-insensitive suffix (`.safetensors`, `.bin`, `.gguf`, `.pt`, `.pth`), sort by relative POSIX path and hash their opaque bytes only with `--hash-large-files` or if their combined total ≤ 100 MiB; otherwise `weights.hashed: false`. This is byte identity only: do not deserialize weights or import a model framework. Explicit single-file local IDs retain their existing suffix-independent behavior. |
```

`case-insensitive`、递归选择、相对路径排序、不解码、单文件不筛选均说明既有实现；
新增行为仅是目录集合加入 `.pth`。本次不改变目录内 symlink 的既有处理或宣称新的遍历安全保证。
无 schema、依赖、规则 ID、严重度表、engine/redaction 或版本修改，不触发 D-41 特殊文件审阅。

### 兼容性与明确成本

- 新生成的目录 lock 纳入 `.pth` 大小和（适用时）聚合 SHA；没有 `.pth` 的输入保持原结果。
- 多格式混合目录的总大小新增 `.pth` 后可能跨越 100 MiB，从自动哈希变为
  `hashed: false` / `sha256: null`；显式 `--hash-large-files` 仍可计算，不更改阈值。
- 原聚合算法、相对路径排序及元数据优先保留。有元数据时 revision 继续优先使用
  config aggregate；单独改变权重通常只改变 local weights 字段，沿既有默认 MEDIUM。
  没有元数据且权重被哈希时，权重 SHA 同时成为 revision，内容变化可触发既有 HIGH。
  大文件未哈希时保持旧的缺少权重 SHA 行为，不虚构修订身份。
- 空目录、仅非权重文件目录、旧四后缀、显式单文件路径及 config/chat-template 处理保持。
- 历史 lock/run 原件不迁移、不重写；只有重新生成 lock 才获得新集合结果。
  `lock --check` 仍只核对声明/规则摘要等既有新鲜度条件，不新增对模型文件内容的重哈希，
  不能用它声称旧 lock 已感知 `.pth` 修改。
- 文件按不透明字节流处理，不验证 PyTorch 格式，不执行 pickle，不导入 torch，也不证明模型可加载。

备选 B：维持原合同，文档说明目录暂不计入 `.pth`，需要时将 local ID 指向单文件。
B 不改变现有目录 lock，但混合分片目录仍无法将 `.pth` 纳入同一聚合身份。

### 实现前独立验收预期

先写失败回归并保存旧实现的实际 RED，再实施 A；控制例保留 PASS。
预期聚合值由规范化的相对文件名及固定字节独立计算，不调用被测聚合 helper 充当 oracle。

| 场景 | 必须核对 |
|---|---|
| 仅 `.pth` 的目录 | 正确字节总数、非空聚合 SHA、完整 local 字段 |
| `.PTH`、嵌套及乱序创建 | 大小写后缀匹配；相对路径稳定排序；重复生成确定性 |
| 混合旧后缀与 `.pth` | 全部符合文件进入同一集合；非权重文件排除 |
| 等于/超过阈值及强制哈希 | `≤` 边界、跨阈值后的完整字段、显式开关恢复哈希 |
| 仅变更 `.pth` 字节 | 新 lock 聚合值变化；相同输入保持；不只比较 summary |
| 元数据存在/不存在 | config 优先保留；对应 diff 路径和既有 MEDIUM/HIGH、退出码 |
| 旧格式、空目录、显式单文件 | 现合同全部保持，不引入空目录新错误或后缀限制 |
| CLI 离线 lock / check / diff | 新 lock 可读，历史 lock 未改，check 不新增内容探测 |
| 不透明内容 | 任意合成字节按原始流哈希，不解码、不导入框架、不联网 |

测试文件以现有 `tests/unit/lock/test_local_resolver.py` 及受影响 CLI/diff 测试为入口。
产品只改后缀集合，规范只替换上述行，另更新 CHANGELOG；若最小改动无法满足预期，先说明原因。
不借此改聚合格式、路径读取边界、阈值、metadata优先级、规则结果、持久化 schema 或其他 suffix。
