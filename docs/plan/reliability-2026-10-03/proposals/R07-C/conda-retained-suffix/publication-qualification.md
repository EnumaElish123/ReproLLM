# D-M-CS current observations: interpretation and publication limits

These are **current-source observations**, not execution of the proposed policy.
The 32 direct-helper cases and 24 integrated current cases are distinct from the
38 future acceptance groups. Candidate-policy executions remain zero.

## Exact semantic scope

The independent literal expectations were frozen before the first run. Both runs
use the unchanged `22e3dbcb799a18b8ef096c6fc42e5f5ab7ae9a0d` source. The integrated
layer uses real non-Git scanner/Context captures and three raw env rules. It does
not invoke the engine, audit/init/export CLI, an installer, a solver, a provider
or resource gates. Empty raw findings do not mean a synthesized engine PASS.

The current `installed_versions()` result is genuinely empty in the locked light
environment; it is checked against the pre-frozen environment expectation and is
not monkeypatched. Only the factual non-Git input seam is supplied to Context.
The profiler reads real call frames and actual graph objects without replacing
parser, Requirement, rule or graph-factory functions.

Full returned Declarations, PyScanResult and all 72 raw rule objects have strict
independent expected/actual projections. The original full observations also
retain selected combined call order, version-field arguments, actual scanner
analysis listings and input hashes. Those extra observed-only trace fields are
not described as having a new literal semantic oracle beyond the frozen fields.
The strict projection comparison preserves types and list order; boolean-type,
declaration-order and raw-finding-severity perturbations affect saved comparison
documents only and are all detected.

## Graph limits

Each integrated case captures one actual graph. **23 of the 24 graphs are empty.**
CS-I08 has exactly one readable requirements node and one complete exact closure,
with no include edge. This is not the earlier D-M-CE 15-node/depth-frontier probe,
and it does not validate nested includes, depth exhaustion, all graph shapes or
a future policy. Actual graph fields and relevant orders are recorded, but the
finite input coverage must remain visible.

## Labels do not certify upstream Conda semantics

Frozen labels are preserved as authored. A label containing `known-nonexact`
first describes the current bounded extractor's absence of exact credit; it is
not a universal Conda validity or version-equivalence certificate.

**In particular, CS-H31's `wildcard-build-known-nonexact-proposed-cost` label must
not be cited as proving that a wildcard build makes its version nonexact.** That
entry lies outside ReproLLM's literal-build exact subset. Upstream version
constraints, build matching and artifact identity are separate questions; the
label does not settle them. The input and expected record are unchanged.

Use CS-H12/CS-H13 and CS-I02 (explicit wildcard *versions*) to illustrate the
proposed conservative cost for currently uncredited version-wildcard use. Compound
forms require their own source qualification. The six numeric RANGE controls,
including `~=`, only describe the existing legacy regex routes; this packet does
not assert that every operator is accepted by an actual Conda client.

## Privacy transformation

Only the private synthetic CS-H32 input/observed native-argument string is replaced
by an explicit UTF-8 byte-length/SHA-256 envelope in public representations. Its
product declaration and diagnostic contain the fixed placeholder/fixed prose and
never include the canary. No product finding or declaration is rewritten for
publication. See the publication copy map for every original/public byte hash
and exact transformation pointer.

Original metadata and projection-packaging hashes bind the **private original
bytes**. They must not be mistaken for hashes of the transformed public files;
the copy map supplies the latter. The observer source is parameterized and can
be published byte-for-byte as `observer.py.txt`; it contains no machine path or
canary value. Raw command receipts remain private because their command-line
arguments contain machine locations.

A hash cannot recover the opaque CS-H32 parameter. Full original observer replay
requires that original frozen input; public sanitized representations do not
claim that the private argument can be reconstructed. Public semantic comparison
data remain inspectable with the transformation made explicit.
