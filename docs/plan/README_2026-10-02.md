# M8-T02 / M8-T08 — README presentation follow-up

Maintainer request (2026-10-02): study several popular, related open-source
projects, summarize their README techniques, then make ReproLLM's README more
polished and informative. This is one documentation task, README-T01, within
the existing documentation and adoption scope (M10-T03).

## Scope and acceptance

- Review official READMEs of five relevant high-star repositories; record
  dated, rounded GitHub star observations and direct source links. Distinguish
  observed structure from our editorial recommendations and avoid implying
  that README design caused their popularity.
- Preserve the verbatim product positioning and five LLM-specific states from
  architecture §2–2.1. Add an original accessible SVG, a short evidence-led demo,
  a minimal first audit, use cases, artifact workflow, profiles/framework links,
  CI, privacy boundaries and contribution/citation navigation.
- Use actual checked output or explicitly labelled excerpts. Do not invent
  dashboards, users, endorsements, benchmarks, supported integrations or a
  completed resource validation. Separate released functionality from main's
  unreleased UX changes; pending specification proposals stay pending.
- Correct the stale status in the linked documentation index so the new
  README entry does not send readers to an obsolete command availability list.
- Validate local links/anchors and SVG, inspect desktop/mobile rendering,
  validate package-description rendering, run existing documentation checks
  and the full quality gate, then five-project L0 Gate A. No command behavior
  changes, new dependencies, model calls, credentials or resource Gate B.

The research summary and final validation record belong in
`docs/research/2026-10-02-readme-review.md`. One documentation commit records
