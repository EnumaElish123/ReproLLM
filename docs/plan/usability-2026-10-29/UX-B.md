## UXR04 的具体接口

沿用 `init --interactive`，不增加命令或配置格式。保持选择 profile、选择任务、填写字段的顺序。
内置研究字段先给出简短含义和取值说明；自定义字段有通用说明，复杂列表/定义继续明确提示手动填写。
空输入保留已有候选或未知值，不推断研究事实。显式保存的命令不重复提问。

每次非空回答在内存中校验类型、范围、枚举及路径；错误在当前字段重试，先前正确回答保留。
错误提示只包含安全字段与修正方式，不重复输入值。输入结束而未完成时返回输入错误，不写文件；
中断仍取消操作。现有写前验证、`--force` 文件保全和隐私要求保持。
显式填写的字符串必须保持字面含义，不能通过 YAML 隐式类型或结构改变其他字段；默认非交互生成文件保持原字节。
不能把自定义配置本身的错误当作可无限重试的单字段错误。

完成提示基于实际生成的声明，计算仍为空的所选 profile 必填字段：缺失、null、空字符串/列表/映射计入；
数值 0 和 false 不算空。目录生成的项目名、已有模型候选、明确选定的任务和已保存命令不误算为未填写。
安全默认项目名另行提示审阅；“已填写”不等于内容已核实，也不等于全部审计规则通过。
列出需要补充的字段，并给出 `reprollm audit .` 下一步。

先写定向验收：错误后重试且保留前值、空输入、检测候选、任务选择、复杂字段、计数为零、
自定义字段、字符串字面保全、私密错误、输入结束/中断与已有文件保全。同步规范 §3.2 和 CHANGELOG。

## UXR05 的具体素材

使用仓库已有 `examples/lm_eval_replay/probe.py` 与 `validation/eval.yaml`，只复制这两个文件到新目录。
此标准库程序读取固定的 lm-eval 配方并记录实际消费值，不加载模型；教程明确区分研究声明和实际运行。
安装/准备单列；主路径只有保存并填写、审计、预览、运行四条命令；查看记录、导出和比较放在后续选项。
说明结果中的缺失信息如何处理，不要求读者为了凑齐 PASS 补写未经确认的事实。

逐条重放教程，记录首次 capture 的命令数、手动编辑点、提示次数和阻塞。
本轮可完成作者重放及开发验收；未观察到的外部用户首次使用不得记为成功采用。
教程入口为 [首次实验](../../tutorials/first-experiment.md)；既有长手册保留为进阶参考。

## 验证矩阵与边界

| 改动 | 必须重验 | 独立预期 |
|---|---|---|
| 交互填写 | 五项目 fresh init 交互变体、错误重试、计数 | 固定源码/旧 manifest 加显式答案，不能从候选输出生成预期 |
| 初始化完成提示 | 五项目默认 init→L1、文本完整对照 | 新提示准确，默认 manifest、完整 L1 结论不变 |
| 共享 init 入口 | 全五项目 Gate A、相关既有变体 | pins、facts、profiles、hints、路径、诊断、JSON gold 保持 |
| 教程 | 一次性目录中逐步实际重放 | 预览无运行，实际 child 和消费记录匹配，未填项如实保留 |

遵循验证工作流：每任务先 RED/GREEN；最终输入执行一次完整质量门，然后执行全部适用五项目验收。
生成 quickstart/CLI 文档变化必须复核。任务提交按顺序，验收报告单独提交，推送 main 后核对五项官方 CI。
这是普通易用性迭代；GPU、付费接口、真实 Hub 门不适用，不更改依赖、schema、规则结论、历史 gold 或发布版本。
主工作区已有九份未提交文件逐字节保留，不纳入提交。
