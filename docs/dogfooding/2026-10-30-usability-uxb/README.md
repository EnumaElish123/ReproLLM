## 定向回归与独立复核

独立复核在完整质量门前发现并关闭了以下问题：

- 新字段列表可能显示私密路径/机器标识，检测候选也不能直接成为未经检查的默认值。
- `project.description` 等未被现有渲染器保存的自定义字段不能在提示中接受后丢失。
- 原本可交互填写的 `training.deepspeed.config` 不能被全 null 的初始配置提前拒绝。
- 某些跨字段错误直到必填 null 被填入后才出现，不能将合法回答反复判为当前字段输入错误。

交互期间仅暂缓“精确落在待填必填 null 路径”的标量类型/枚举错误；全局或其他字段的实际结构错误只给一次配置指导。
最终写入前仍严格验证完整 Manifest。三份完整 Manifest 语义与 YAML 字节对照证明有效自定义路径流程与旧 `8ea80e8` 一致；
额外的真实 CLI 复现确认潜伏的跨字段错误返回一次私密 exit 2，且没有产物。
