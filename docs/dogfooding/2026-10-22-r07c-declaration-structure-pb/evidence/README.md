# D-M-S final evidence

The command records preserve original raw hashes, exits and elapsed times. source-index.json
maps each public artifact to its original hash and its projected public hash. Only exact known
machine roots are replaced with logical tokens; all business fields, JSON types/order, line
endings and EOF bytes remain. No timestamp is rewritten.

validation/gate retains complete L0/facts/L1 reports, comparisons, diagnostics, generated init
files and default exports for five pinned targets. validation/oracle-binding.json references
pre-existing committed expected files by source path, commit and hash without duplicating them.
validation/synthetic-expected contains 18 prewritten full report oracles;
validation/synthetic retains actual/repeat/restored/suppressed reports and comparisons.

Quality JUnit/coverage bodies, detailed quality logs and initial failure bodies remain private
with original hashes and sizes in source-index.json. Published summaries retain real counts,
coverage, command exits and timings. The first full quality attempt remains FAIL; its
original inputs, tools and launch logs retain hashes. The exact 51-case short-path repair
probe is separate from the final full quality retry and does not substitute for that gate.
The first extended-path Gate A attempt remains FAIL at clone; its base report bodies
remain private by hash. The final fresh Gate A reports are preserved in full exactly once.
gate-adapter retains the precise bootstrap/clone-root-only patch and its hash receipt;
validation/clone-path-probe retains the independent clone capability receipt.
Synthetic exports retain full output but only their
predeclared summary/visibility assertions are claimed, not independent whole-export gold.

This evidence does not replace final-head CI or unblock resource gates. No release is made.
