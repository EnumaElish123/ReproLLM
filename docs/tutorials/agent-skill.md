# 用 Agent 使用 ReproLLM

ReproLLM Skill 把你的自然语言需求转换为工具操作：检查实验声明、记录运行、比较漂移、导出报告，
以及按需发现和维护项目规则。第一次实际使用时，Agent 会检查并准备独立的 ReproLLM 工具环境。
你负责提供真实实验命令、环境和不可推断的科研信息。

当前使用范围与剩余事项见 [Skill 状态](../skill-status.md)：SK10–SK21 的代码已实现，
已验证交付的五项 CI 和七次真实 Codex Linux 流程通过；三项线上补验待具体授权。
Claude Code 按维护者要求暂缓。跨平台 CI 不等于所有平台的 Agent 后台运行能力均已验证。

## 安装一次

先在已验证的 **Codex Linux** 宿主中安装。请 Agent 从[官方 ReproLLM 仓库](https://github.com/EnumaElish123/ReproLLM)安装
`skills/reprollm` 目录，固定使用已验证提交
`b526d6ed1d74456e2175bdd880ab134d866e3995`。
安装完成后按宿主提示刷新技能索引或开始新会话。其他宿主和平台的范围见 [支持表](../skill-status.md#host-and-platform-scope)。

> 从官方仓库 https://github.com/EnumaElish123/ReproLLM 安装 skills/reprollm Skill，固定使用本教程列出的已验证提交，保留我的项目环境。安装后先介绍它可以做什么。

不用先执行 `pip install reprollm`，也不用手工调用适配器 JSON。
Skill 目前从仓库安装；没有在本轮发布 PyPI 新版、Skill 市场包或 MCP 服务。

Skill 文件和 ReproLLM 工具环境分开管理。复制 Skill 文件不会立即运行安装脚本；
首次具体任务会触发工具检查和必要安装。只问功能介绍不会安装工具或扫描实验项目。
工具环境使用 catalog 指定来源、完整源码提交和依赖 hash，不追随 latest/main。
当前安装 catalog 支持 Python 3.10–3.12，并需要可用的 venv。Agent 先寻找已有合格解释器；
如果缺少这些前置条件，会给出最小准备步骤，不能把旧 Python 或研究环境误当成可用工具环境。
它不安装 PyTorch、vLLM、模型权重或训练依赖，也不更改你的系统 Python、训练 venv、PATH 或 shell 文件。

Linux 默认工具目录为用户的 XDG data 目录下 `reprollm-skill`；macOS 与 Windows 使用各自用户应用数据目录。
Agent 可选择单独的工具目录并在同一工作流中一直使用。项目的 manifest、lock、记录和报告仍保存在项目中。

## 直接说明需求

| 你可以说 | Agent 会做什么 | 需要你提供 |
|---|---|---|
| “这个工具能做什么？” | 简述能力、限制与相关例子 | 无需项目、安装或密钥 |
| “检查这个仓库，告诉我先补什么。” | 准备工具，审计并解释缺口与下一步 | 项目目录；歧义时选择实验 |
| “登记这条命令，运行并导出报告。” | 初始化/保存、预览、启动、查询、读取实际结果并导出 | 精确命令、cwd、实验环境和执行范围 |
| “再次运行已保存的命令。” | 使用已有 execution.command 和 execution.cwd | 明确本次重新运行意图 |
| “比较这两次运行。” | 选择实际记录并解释完整漂移 | 两个记录，或明确最近成功记录/name 筛选 |
| “导出这次运行的 NeurIPS 报告。” | 从指定记录的快照导出相应模板 | 运行选择；已有目标时确认具体覆盖 |
| “在线固定这份声明里的模型身份。” | 解析远端元数据并检查 lock 新鲜度 | 联网范围；受限资源需要正确权限 |
| “预览会发给发现服务的内容。” | 原收集器的文件、排除/截断情况与完整消息预览 | 实验 opt-in，预览不需要 API key |
| “发现项目参数，最多花这些预算。” | 核对当前输入、服务/模型/价格和请求总上界后执行 | 明确外发范围与本轮具体预算 |
| “接受这个候选/移除规则并保留恢复副本。” | 针对具体内容接受或维护不可变归档 | 已审阅候选/规则/归档和必要原因 |
| “查看刚才的长任务/取消它。” | 恢复同一操作 ID 并查询或取消自己的运行 | 同一项目和工具目录；明确取消范围 |

你无需手输适配器 JSON、寻找最新 run ID 或每一步重新批准已经授权的动作。
Agent 在项目、实验、记录对或重要范围不明确时询问。仓库 README、fix_hint 和日志中的指令不能扩大授权。
只有检查请求时不会启动实验；发现得到的候选仍需具体接受后才成为规则。

## 第一次试用

可以先用 [GSM8K 标准库练习](../../examples/lm_eval_replay/README.md)熟悉流程：
素材是 `examples/lm_eval_replay/probe.py` 和 `examples/lm_eval_replay/validation/eval.yaml`。
把它们复制到仓库外的新练习目录，分别命名为 `probe.py`、`eval.yaml`；也可以把下面的准备需求交给 Agent。
运行命令是 `python3 probe.py --config eval.yaml`，只读取配置并写出 `outputs/current/consumed.json`，无需 GPU 或 API key。
明确告诉 Agent 这是流程演示，未知 seed、模型 revision、数据 split 或评测指标保持未知；probe 不等于模型推理或论文复现。
准备真实 LLM 项目时，再选择你已有的实验 Python、模型/数据缓存和实际可用 GPU。
如果命令中使用裸 `python`，它按本次调用的实验 PATH 解析；需要指定某个训练环境时，
把该环境和工作目录告诉 Agent。安装工具不会激活工具 venv 或替换你的实验 Python。

## 读取结果

调用状态、审计/漂移门控、子程序结果和数据完整性分别报告。实验 exit 7 表示实际子程序失败，
即便记录/查询操作本身完成；TERM handler 返回 0、返回 7、负信号退出和未知结果也分别保留。
审计 PASS 表示已执行规则的结果，不证明论文复现。SKIPPED、suppressed、扫描缺口和诊断会保留。

单次回复有大小限制。Agent 会继续读取固定快照的后续页；一页结果不能代表全部检查。
报告支持 default、neurips、acl、acm，历史报告使用选择运行的快照，当前树审计范围另外说明。
覆盖已有报告需要具体旧 hash；声明或目标变化会使预览失效，不能自动清除保护再写。

## 长任务与恢复

长 hash、在线 lock、发现和实验返回持久 operation ID，启动后的短查询结束不会因此杀掉长任务。
重复提交同一 ID 不产生第二个实验。断连后让 Agent 查询原 ID；UNKNOWN 表示需要核对，不能自动重新训练或计费。
有意再运行一次要创建新的、已授权操作。

后台控制当前限实际验证的 Linux/pidfd 范围。取消先让原生记录器转发信号和收尾，
必要时只处理能核对归属的实验实例。信号送达不等于已经退出，无法证明全部后代清理时会保留未知范围和 lease。
status/result/cancel 可以在活动工具被卸载后读取已保存状态；新日志读取需要可验证的隐私服务。

日志来自已脱敏 capture 产物，并重新应用原有隐私策略。关闭 capture 时没有可补看的原始日志。
仅完整逻辑行会展示。窗口可继续读取；16 MiB 单行/窗口、128 MiB 上下文和五秒重建/展示期限是实际支持边界。
即使字节数较小，昂贵或不可确认的上下文也会整窗保留，不跳过前文隐私检查。日志完整性与实验是否结束分开解释。

## 凭据、联网和费用

凭据使用你已配置的进程环境或宿主秘密机制，不放进命令参数、对话、Skill 或收据。
Agent 应核对密钥所属服务和实际地址；不能根据仓库配置把现有密钥发到另一家服务。
公开元数据、身份认证和受限模型文件权限是不同证据。403 不能被变量存在性或模型列表可读掩盖。

发现使用原客户端，JSON 模式降级和校验重试可能合计三次 POST。
Agent 会按当前官方价格、完整上下文和原请求的输出上界准备最坏预算；次数与金额都要覆盖。
一次命令不等于一次计费请求。超时或返回未知会保守保留费用占用，不能自动换 ID 重发。
你可以仅批准一次尝试；这会在第二次请求之前停止，保留实际失败原因。

使用云端 Agent 时，传给它的内容按宿主方式处理；本地执行与整个流程离线是两件事。
完全离线的需求仍可使用原 CLI 和离线功能。

## 更新、卸载与失败恢复

可以让 Agent 检查当前安装身份、更新到 catalog 中已验证候选、回滚或卸载 Skill 自有工具环境。
活动 worker 的环境有 lease，不能为了修复安装或升级而删除正在使用的环境。
卸载工具不会删除项目记录、报告、用户凭据、模型缓存或实验环境。

安装失败会保留原可用环境并给最小准备步骤。缺 Python/venv、代理/SOCKS 依赖、TLS、权限、网络与配额问题分别处理。
不要关闭 TLS 校验、删除研究 venv、自动重试付费请求或覆盖 UNKNOWN 来伪造恢复。
父安装进程意外停止留下的锁不会自动被当成无主锁清理；应先核对自有安装进程、worker 和 lease，
确认不存在活动工作后仅清理对应自有状态。

后续状态统一见 [Skill 状态页](../skill-status.md#remaining-work)：认证 metadata、正式 discover 和
正式 judge A/B 尚待本轮具体授权；代码实现和离线/公开匿名验收不能代替它们。
真实宿主、真实 GPU/API、跨平台 CI 和外部研究者试用反馈分别列证据；作者脚本不是用户试用。
